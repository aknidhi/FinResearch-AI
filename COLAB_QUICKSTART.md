# Google Colab Quickstart — FinSight AI Global

1. Upload the repository to Google Drive or clone your GitHub repository.
2. Open `notebooks/Financial_Research_AI_Agent_Colab.ipynb` in Google Colab.
3. Run the installation cell.
4. Test simple global tickers such as `AAPL`, `TSLA`, `SAP.DE` and `RELIANCE.NS`.
5. Set `GROQ_API_KEY` only inside the notebook session.
6. Run the technical, news and AI fallback smoke tests.

The production UI is Streamlit; Colab is used for development/testing and demonstration.
