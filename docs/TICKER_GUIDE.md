# Global Ticker Guide

## The simple rule

**Type the ticker symbol, not the company name.**

Examples:

- `AAPL` → Apple
- `TSLA` → Tesla
- `MSFT` → Microsoft
- `NVDA` → NVIDIA
- `SAP.DE` → SAP on Xetra/Germany
- `VOD.L` → Vodafone on London Stock Exchange
- `7203.T` → Toyota on Tokyo Stock Exchange
- `0700.HK` → Tencent on Hong Kong Stock Exchange
- `RELIANCE.NS` → Reliance Industries on NSE India

## Bare ticker vs exchange-qualified ticker

For many US securities, a bare ticker is enough. For international exchanges, add the Yahoo Finance suffix when necessary.

The app tries to resolve bare tickers automatically. Because the same ticker can exist on multiple exchanges, the application displays the resolved company and exchange before the main analysis.

If the wrong instrument is resolved, use the exchange-qualified Yahoo Finance symbol.
